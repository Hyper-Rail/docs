This quickstart takes you from a new test key to a priced quote, without moving real money. Every call runs in **test mode**.

<RequestExample>

```bash cURL
curl "https://api.hyperrails.io/api/v1/partners/rates?base=GHS&quote=NGN" \
  -H "Authorization: Bearer $HYPERRAILS_SECRET_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://api.hyperrails.io/api/v1/partners/rates?base=GHS&quote=NGN",
  { headers: { Authorization: `Bearer ${process.env.HYPERRAILS_SECRET_KEY}` } }
);
console.log(await res.json());
```

```python Python
import os, requests

res = requests.get(
    "https://api.hyperrails.io/api/v1/partners/rates",
    params={"base": "GHS", "quote": "NGN"},
    headers={"Authorization": f"Bearer {os.environ['HYPERRAILS_SECRET_KEY']}"},
)
print(res.json())
```

</RequestExample>

## Before you start

- A HyperRails account. See [Onboard with us](/documentation/onboarding).
- API access enabled on your account. Contact [support@hyperrails.io](mailto:support@hyperrails.io) if it isn't.

<Steps>
  <Step title="Get your test secret key">
    In the [dashboard](https://app.hyperrails.io), switch to **test mode**, then go to **Credentials → API Keys** and copy your secret key. It starts with `sk_test_`.

    <Warning>
      Your key is shown **only once**. After that it's stored hashed and can't be viewed again, so save it now. If you lose it, generate a new one.
    </Warning>

    Store it as an environment variable, never in code:

    ```bash
    export HYPERRAILS_SECRET_KEY="sk_test_..."
    ```

    <Warning>
      Your secret key grants full account access. Keep it on your server. See [Integration security](/documentation/guides/integration-security).
    </Warning>
  </Step>

  <Step title="Make your first call">
    Read a reference rate. The request and response are shown alongside this page, in cURL, Node.js and Python.

    Every request authenticates the same way: `Authorization: Bearer <secret key>`. The `sk_test_` prefix is what makes this a test-mode call. See [Authentication](/api-reference/authentication).
  </Step>

  <Step title="Check there's liquidity">
    A rate doesn't mean anyone is offering to trade. Check liquidity listings to see who is, and how much they can fill:

    <CodeGroup>

    ```bash cURL
    curl https://api.hyperrails.io/exchange/api/v1/partners/marketplace/listings \
      -H "Authorization: Bearer $HYPERRAILS_SECRET_KEY"
    ```

    ```javascript Node.js
    const res = await fetch(
      "https://api.hyperrails.io/exchange/api/v1/partners/marketplace/listings",
      { headers: { Authorization: `Bearer ${process.env.HYPERRAILS_SECRET_KEY}` } }
    );
    const { content } = await res.json();
    console.log(content.map((l) => [l.pair, l.rate, l.availableBalance]));
    ```

    ```python Python
    res = requests.get(
        "https://api.hyperrails.io/exchange/api/v1/partners/marketplace/listings",
        headers={"Authorization": f"Bearer {os.environ['HYPERRAILS_SECRET_KEY']}"},
    )
    for l in res.json()["content"]:
        print(l["pair"], l["rate"], l["availableBalance"])
    ```

    </CodeGroup>

    Note the base URL: listings live on `/exchange/api/v1`. Pick a pair whose `availableBalance` covers the amount you'll quote.
  </Step>

  <Step title="Find the account to settle into">
    A quote needs the `accountId` of the balance that receives the money:

    ```bash
    curl https://api.hyperrails.io/api/v1/balances/currency/NGN \
      -H "Authorization: Bearer $HYPERRAILS_SECRET_KEY"
    ```

    Need test funds? Use the [Funding Simulator](/documentation/testing/funding-in-test-mode).
  </Step>

  <Step title="Price your first quote">
    Create an express quote for 5 GHS into NGN:

    <CodeGroup>

    ```bash cURL
    curl -X POST https://api.hyperrails.io/exchange/api/v1/partners/marketplace/express/quote \
      -H "Authorization: Bearer $HYPERRAILS_SECRET_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "sourceCurrency": "GHS",
        "destinationCurrency": "NGN",
        "amount": 5,
        "amountDirection": "source",
        "accountId": "YOUR_NGN_ACCOUNT_ID"
      }'
    ```

    ```javascript Node.js
    const res = await fetch(
      "https://api.hyperrails.io/exchange/api/v1/partners/marketplace/express/quote",
      {
        method: "POST",
        headers: {
          Authorization: `Bearer ${process.env.HYPERRAILS_SECRET_KEY}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          sourceCurrency: "GHS",
          destinationCurrency: "NGN",
          amount: 5,
          amountDirection: "source",
          accountId: "YOUR_NGN_ACCOUNT_ID",
        }),
      }
    );
    const quote = await res.json();
    console.log(quote.quoteId, quote.allocationResult.weightedAverageRate);
    ```

    ```python Python
    res = requests.post(
        "https://api.hyperrails.io/exchange/api/v1/partners/marketplace/express/quote",
        headers={"Authorization": f"Bearer {os.environ['HYPERRAILS_SECRET_KEY']}"},
        json={
            "sourceCurrency": "GHS",
            "destinationCurrency": "NGN",
            "amount": 5,
            "amountDirection": "source",
            "accountId": "YOUR_NGN_ACCOUNT_ID",
        },
    )
    quote = res.json()
    print(quote["quoteId"], quote["allocationResult"]["weightedAverageRate"])
    ```

    </CodeGroup>

    You get back a quote in `PENDING`, with a `quoteId`, the `allocationResult` showing who fills it, and the totals. Quotes are valid for 30 minutes.
  </Step>
</Steps>

## Troubleshooting

| What you see | What it means | What to do |
|---|---|---|
| **401** | Missing or invalid secret key | Check the `Authorization: Bearer sk_test_...` header |
| **404** with an empty body on the rate call | No rate exists for that pair | Try another pair. Check the status code before parsing the body |
| **400** `missing_parameter` | `base` or `quote` missing | Rates use `base` and `quote`, not `source` and `destination` |
| **400** `No providers available` | Nobody offers the pair | Pick a pair from the listings in step 3 |
| **400** `Unable to fulfill requested volume` | Bigger than the provider holds | Quote a smaller amount |
| **401** with an empty body on accept | `express` left in the accept path | Accept is `/partners/marketplace/quote/{id}/accept` |
