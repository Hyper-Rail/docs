# Audit Logs

> Review a chronological record of actions taken on your HyperRails account.

Navigate to **Settings → General → Audit logs**.

Audit logs record security- and access-relevant events, including:

* User invites, role changes, and removals
* Login and 2FA changes
* API key and webhook secret generation/rotation
* Merchant settings changes

Each entry includes the **actor** (user or API key), **action**,
**timestamp**, and, where applicable, the **before/after values**. Only
Admins can view audit logs.
