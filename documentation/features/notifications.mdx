# Notification Preferences

> Control when and how you receive email, webhook, and in-app alerts.

Navigate to **Settings → General → Notifications**.

| Setting | Default | Description |
|---|---|---|
| Send email notification for settlement transactions | On | Emails you each time a settlement transaction completes. |
| Send email notifications for account transactions | On | Emails you for wallet/account-level transactions (funding, payouts). |
| Send webhook notification for account transactions | On | Delivers account transaction events to your configured [Webhook URL](/documentation/webhooks/overview) in addition to (or instead of) email. |
| Send In-app Notifications | On | Shows alerts in the dashboard notification bell. |

Toggling a setting off stops that channel immediately; it does not affect
past notifications already sent.
