## What to include

The more of these you include, the faster we can investigate:

- **Mode:** test or live
- **IDs:** the `quoteId`, payout `reference`, virtual account `id` or `walletId`
- **Trace ID:** the `traceId` from the error response
- **Webhook ID:** `x-hyperrails-webhook-id`, if it's about a webhook
- **The request and response,** with your secret key removed
- **When it happened,** with the timezone

<Warning>
  Never send your secret key, webhook secret or 2FA recovery codes to anyone, including HyperRails support. If you think a key has been exposed, regenerate it from **Dashboard → Credentials → API Keys** straight away.
</Warning>

## Higher Payout Frequency or Limits

To request a weekly payout cycle, or to ask about limits on your account, email [support@hyperrails.io](mailto:support@hyperrails.io). See [Payout structure](/documentation/features/payout-structure) and [Transaction limits](/documentation/limits).
