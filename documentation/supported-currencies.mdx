This is the authoritative list of what HyperRails supports. If this page and any other page disagree, this page is correct. Currency-pair tickers on the dashboard may include preview or coming-soon pairs.

<Warning>
  Stablecoins sent on an unsupported network, or to an incorrect address, may be irretrievable and permanently lost. Always confirm the network (chain) before sending.
</Warning>

## Fiat Currencies

| Currency | Code | Wallet funding | Payouts | Fiat-to-fiat exchange |
|---|---|:---:|:---:|:---:|
| Nigerian Naira | `NGN` | ✓ | ✓ | ✓ |
| Ghanaian Cedi | `GHS` | ✓ | ✓ | ✓ |
| Kenyan Shilling | `KES` | ✓ | ✓ | ✓ |
| South African Rand | `ZAR` | ✓ | ✓ | ✓ |
| West African CFA Franc | `XOF` | ✓ | ✓ | ✓ |
| US Dollar | `USD` | ✓ | ✓ | ✓ |
| British Pound | `GBP` | ✓ | ✓ | ✓ |
| Euro | `EUR` | ✓ | ✓ | ✓ |

Fiat-to-fiat exchange is bridged through stablecoins. Additional corridors and currencies are in controlled rollout, so contact [support@hyperrails.io](mailto:support@hyperrails.io) if you need one that isn't listed.

### USD Payouts

USD Payouts are sent over **SWIFT/BIC**. ACH and Fedwire are not available yet.

## Networks

When you create a pool or view listings for a pair that includes a stablecoin, you pick the network (chain) to use.

- Base
- Ethereum
- Polygon
- Stellar
- Tron

## Check Support Programmatically

Don't hardcode these lists in production integrations. Query them instead:

```bash
curl https://api.hyperrails.io/api/v1/trade-pairs/supported/currencies/fiat \
  -H "Authorization: Bearer sk_live_..." \
  -H "x-service-source: YourAppName"

curl https://api.hyperrails.io/api/v1/trade-pairs/supported/currencies/stables \
  -H "Authorization: Bearer sk_live_..." \
  -H "x-service-source: YourAppName"

curl https://api.hyperrails.io/api/v1/trade-pairs/supported/chain \
  -H "Authorization: Bearer sk_live_..." \
  -H "x-service-source: YourAppName"
```
